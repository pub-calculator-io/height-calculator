Predict your child's future adult height with our free Height Calculator. Based on scientific data, it accurately estimates growth and converts height units.

[https://www.calculator.io/height-calculator/](https://www.calculator.io/height-calculator/)

== Usage ==

Add the Height Calculator shortcode to your page, post or sidebar:

`[calcio_height_calculator]`

Add the following code to your template where you would like the Height Calculator to appear:

`<?php display_calcio_height_calculator(); ?>`

== Installation ==

1. Upload the Height Calculator /calcio_height_calculator/ folder to the /wp-content/plugins/ directory.
2. Activate the Height Calculator plugin through the "Plugins" menu in WordPress.
